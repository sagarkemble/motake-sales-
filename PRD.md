1. Create a product page where salesman can see the products list with available quantity
2. Add to cart button for each product so that product can be added into cart with quantity.

## Task 2: Cart Page

Making the successful order is 3 step process
1. Finalize product added to the cart
2. Add the customer details -> from the dropdown or add new customer details
3. Select the order type -> Order / Pre-Order

## Task 3: GatePass

1. One page to show today & gatepass history

2. Should be able to see the detail of pre-order in details after clicking the respective pre-order
3. In case of "Booked" pre-order salesman can mark it as completed.
